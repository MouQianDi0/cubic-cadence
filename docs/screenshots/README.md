# 界面截图占位目录 / Screenshots Placeholder

此目录用于存放 README「界面预览」章节引用的截图素材。

This directory holds the screenshots referenced by the README "Screenshots" section.

## 文件命名 / Filenames

| 文件名 / Filename | 对应界面 / Screen |
| --- | --- |
| `music-library.png` | 音乐库主页 / Music Library |
| `login-qr.png` | 扫码登录 / QR-code Sign-in |
| `playlist-detail.png` | 歌单详情 / Playlist Detail |
| `settings.png` | 设置界面 / Settings |

## 如何替换 / How to Replace

1. 将你的截图放入本目录。
2. 保持与上表一致的文件名（推荐 `.png`，也可使用 `.jpg`）。
3. 如需更换格式，请同步修改 `README.md` 中对应图片标签的扩展名。

1. Drop your screenshots into this folder.
2. Keep the filenames in the table above (`.png` recommended, `.jpg` also works).
3. If you change the format, update the matching image extension in `README.md`.

## 推荐规格 / Suggested Specs

- 分辨率：1920×1080 或等比例缩放的 1280×720。
- 格式：PNG（无压缩损失）或 JPEG（更小体积）。
- 内容：尽量完整展示界面边框与文字，避免过度裁剪。

- Resolution: 1920×1080, or a proportional 1280×720.
- Format: PNG (lossless) or JPEG (smaller size).
- Content: keep the full UI frame and text visible; avoid over-cropping.
